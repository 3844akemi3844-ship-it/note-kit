# A＋salon ランディングページ

40代女性向けヘッドマッサージサロン「A＋salon」（福岡県宗像市くりえいと）のLP。

## 2種類あります

| ファイル | 中身 |
| --- | --- |
| `index.html` | **デザイン画像をそのまま縦に並べただけのLP**（現在の本番用） |
| `coded.html` | 同じデザインをHTML/CSSで組み直したもの（文字が選択・検索でき、SEOにも有利） |

どちらもビルド不要です。使うほうを `index.html` として、`assets/` と一緒にサーバーへアップロードしてください。

---

## 1. `index.html`（画像を貼るだけ版）

`assets/images/lp-01.jpg` 〜 `lp-05.jpg` を上から順に表示しているだけの、とてもシンプルな構成です。

### やること

1. **画像の差し替え** — 現在入っているのは「差し替えてください」と書かれた**仮画像**です。
   いただいたデザイン画像を、下の名前で `assets/images/` に上書きしてください。

   | ファイル名 | 中身 |
   | --- | --- |
   | `lp-01.jpg` | 1枚目：ファーストビュー |
   | `lp-02.jpg` | 2枚目：こんなお悩み・特長 |
   | `lp-03.jpg` | 3枚目：60分後、こんな感覚を。 |
   | `lp-04.jpg` | 4枚目：メニュー・料金 |
   | `lp-05.jpg` | 5枚目：セラピスト紹介 |

   - 横幅は **1000〜1200px** 程度あれば十分きれいです（縦の長さは自由、画像ごとに違っても大丈夫）。
   - 枚数を増やす／減らすときは `index.html` の `<img>` の行を足す／消すだけです。

2. **リンク先の差し替え** — `href="#reserve"` になっているボタンを実際のURLにしてください。
   該当箇所には `<!-- ▼ ... -->` のコメントを入れています。
   - 「ご予約はこちら」（画面下に固定のボタン／ページ最下部のボタン） … 予約フォーム・予約サイトのURL
   - 「LINEで相談する」 … LINE公式アカウント（`https://lin.ee/xxxx`）。不要ならその行ごと削除してください。

3. 画面下に常に出る予約ボタンが不要なら、`index.html` の `<div class="fixed-cta">…</div>` を削除してください。

### 画像だけのLPの注意点

- 画像内の文字は検索エンジンに読まれません。`<img>` の `alt` に文言を入れてあるので、そこは残しておくことをおすすめします。
- 料金改定のときは画像の作り直しが必要です。文字の修正が多くなりそうなら `coded.html` のほうが楽です。

---

## 2. `coded.html`（HTMLで組んだ版）

同じデザインをHTML/CSSで再現したものです。文字はテキストなので、料金や文言の修正はHTMLを直接編集するだけで済みます。

```
coded.html                 … ページ本体（全セクション）
assets/css/style.css       … スタイル（デザイントークンは :root にまとめています）
assets/js/main.js          … スクロール時のふわっとした表示演出のみ
assets/images/             … 写真・装飾
```

セクションの並びはデザイン画像どおりです。

1. ファーストビュー
2. こんなお悩み、ありませんか？ ＋ A＋salonのヘッドマッサージ（3つの特長）
3. 60分後、こんな感覚を。
4. メニュー・料金
5. セラピスト紹介
6. ご予約（デザイン画像にはありませんが、導線として最後にCTAを置いています）

### 差し替えが必要な箇所

- **写真** … `hero.jpg` / `feel-1〜3.jpg` / `menu-1〜5.jpg` / `therapist.jpg` は以前のデザイン画像から切り出した**仮画像**です。画質が粗く権利も不明なため、公開前に必ずサロンの実写真へ差し替えてください（同じファイル名で上書きすればレイアウトはそのままです）。
- **リンク先** … `href="#reserve"` のボタン（ご予約×2／LINE）を実URLに。
- **文言・料金** … すべて `coded.html` に直接書いています。

### デザインについて

- 配色・余白・書体は `assets/css/style.css` 冒頭の `:root` で一括管理しています。
  （`--gold` で罫線やチェックのゴールド、`--olive` でCTAボタンの色が一括で変わります）
- 書体は Google Fonts の **Shippori Mincho**（見出し）/ **Noto Serif JP**（本文）/
  **Klee One**（手書き風）/ **Parisienne**（A calmer me.）。
- 最大幅600pxの1カラム。見出し・本文は `clamp()` で可変にしているので、320px幅〜600px幅で改行位置が崩れません。
