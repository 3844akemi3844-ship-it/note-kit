# A＋salon ランディングページ

40代女性向けヘッドマッサージサロン「A＋salon」（福岡県宗像市くりえいと）のLP。
いただいたデザイン画像（全5カット）の構成・配色・文言をそのまま再現した、静的HTML1枚構成です。

## 構成

```
index.html                 … ページ本体（全セクション）
assets/css/style.css       … スタイル（デザイントークンは :root にまとめています）
assets/js/main.js          … スクロール時のふわっとした表示演出のみ
assets/images/             … 写真・装飾
```

セクションの並びはデザイン画像どおりです。

1. ファーストビュー（頭から、ふっと軽くなる。／ご予約はこちら）
2. こんなお悩み、ありませんか？ ＋ A＋salonのヘッドマッサージ（3つの特長）
3. 60分後、こんな感覚を。
4. メニュー・料金
5. セラピスト紹介
6. ご予約（デザイン画像にはありませんが、導線として最後にCTAを置いています）

## 公開のしかた

ビルド不要です。`index.html` と `assets/` をそのままサーバーにアップロードすれば公開できます。
ローカルで確認する場合は `index.html` をブラウザで開くだけでOKです。

## 差し替えが必要な箇所

### 1. 写真（重要）

`assets/images/` の写真は、**以前のデザイン画像から切り出した仮の画像**です。
画質が粗く、権利関係も不明なため、**公開前に必ずサロンの実写真に差し替えてください**。
同じファイル名で上書きすれば、レイアウトはそのまま置き換わります。

| ファイル | 使用箇所 | 推奨サイズ（目安） |
| --- | --- | --- |
| `hero.jpg` | ファーストビューの施術写真 | 縦長 900×1200px |
| `feel-1〜3.jpg` | 「60分後、こんな感覚を。」3枚 | 横長 1000×420px |
| `menu-1〜4.jpg` | メニューカード4枚 | 横長 600×400px |
| `menu-5.jpg` | 全身デトックスセラピー（横長カード） | 横長 1100×345px |
| `therapist.jpg` | セラピスト紹介 | 縦長 600×840px |
| `leaf.svg` | 各所の葉っぱ装飾（SVG） | 差し替え不要 |

> デザイン画像の葉っぱは水彩タッチですが、ここでは軽量なSVGの線画で代用しています。
> 水彩の素材（PNG）に差し替える場合は `leaf.svg` を同名の画像に置き換えるか、
> `index.html` の `class="deco"` の `src` を変更してください。

### 2. リンク先

`index.html` 内の `href="#reserve"` になっているボタンを、実際のURLに差し替えてください。
該当箇所には `<!-- ▼ ... -->` のコメントを入れています。

- 「ご予約はこちら」×2（ファーストビュー／ページ下部） … 予約フォーム・予約サイトのURL
- 「LINEで相談する」 … LINE公式アカウント（`https://lin.ee/xxxx`）

### 3. 文言・料金

すべて `index.html` に直接書いています。料金改定などはHTMLを直接編集してください。

## デザインについて

- 配色・余白・書体は `assets/css/style.css` 冒頭の `:root` で一括管理しています。
  （例：`--gold` を変えると罫線やチェックのゴールドが、`--olive` を変えるとCTAボタンの色が一括で変わります）
- 書体は Google Fonts の **Shippori Mincho**（見出し）/ **Noto Serif JP**（本文）/
  **Klee One**（「わたしに、やさしい時間を。」の手書き風）/ **Parisienne**（A calmer me.）を読み込んでいます。
- デザイン画像がスマートフォン想定のため、最大幅600pxの1カラムで、PCでは中央寄せで表示されます。
- 見出し・本文は `clamp()` で画面幅に応じて可変にしているため、320px幅から600px幅まで改行位置が崩れません。
