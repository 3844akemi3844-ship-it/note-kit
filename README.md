# A＋salon ランディングページ

40代女性向けヘッドマッサージサロン「A＋salon」（福岡県宗像市くりえいと）のLP。
いただいたデザイン画像の構成・配色・文言をそのまま再現した、静的HTML1枚構成です。

## 構成

```
index.html                 … ページ本体（全セクション）
assets/css/style.css       … スタイル（デザイントークンは :root にまとめています）
assets/js/main.js          … スクロール時のふわっとした表示演出のみ
assets/images/             … 写真・装飾
```

## 公開のしかた

ビルド不要です。`index.html` と `assets/` をそのままサーバーにアップロードすれば公開できます。
ローカルで確認する場合は `index.html` をブラウザで開くだけでOKです。

## 差し替えが必要な箇所

### 1. 写真（重要）

`assets/images/` の写真は、**いただいたデザイン画像から切り出した仮の画像**です。
画質が粗く、権利関係も不明なため、**公開前に必ずサロンの実写真に差し替えてください**。
同じファイル名で上書きすれば、レイアウトはそのまま置き換わります。

| ファイル | 使用箇所 | 推奨サイズ（目安） |
| --- | --- | --- |
| `hero.jpg` | ファーストビューの人物写真 | 縦長 800×1200px |
| `worry.jpg` | 「こんなお悩み〜」の人物写真 | 縦長 600×800px |
| `feel-1〜3.jpg` | 「60分後、こんな感覚を。」3枚 | 正方形に近い 700×660px |
| `range.jpg` | 「施術範囲」の横顔写真 | 縦長 650×1050px |
| `menu-1〜4.jpg` | メニューカード4枚 | 横長 600×400px |
| `menu-5.jpg` | 全身デトックスセラピー（横長カード） | 横長 1100×360px |
| `therapist.jpg` | セラピスト紹介 | 縦長 400×820px |
| `leaf.svg` | 各所の葉っぱ装飾（SVG） | 差し替え不要 |

### 2. リンク先

`index.html` 内の `href="#reserve"` になっているボタンを、実際のURLに差し替えてください。
該当箇所には `<!-- ▼ ... -->` のコメントを入れています。

- 「ご予約はこちら」×2 … 予約フォーム／予約サイトのURL
- 「LINEで相談する」 … LINE公式アカウント（`https://lin.ee/xxxx`）
- 「その他のお客様の声を見る」 … 口コミページのURL

### 3. 文言・料金

すべて `index.html` に直接書いています。料金改定などはHTMLを直接編集してください。

## デザインについて

- 配色・余白・フォントサイズは `assets/css/style.css` 冒頭の `:root` で一括管理しています。
  （例：`--gold` を変えるとボタンや罫線のゴールドが一括で変わります）
- 書体は Google Fonts の **Shippori Mincho**（見出し）/ **Noto Serif JP**（本文）/ **Parisienne**（英字の筆記体）を読み込んでいます。
- デザイン画像がスマートフォン想定のため、最大幅600pxの1カラムで、PCでは中央寄せで表示されます。
- スマートフォン（320px幅）からPCまで崩れないように調整済みです。
